# 📦 Приложение Orders

Приложение `orders`  отвечает за хранение информации о заказах пользователей и содержимом заказов (продуктах в заказе).

---

## 🗂 Модели

### 1. Order
Представляет отдельный заказ пользователя. 
История заказов (кто и какой заказ сделал).

`dataset_order_id` — уникальный идентификатор заказа из датасета.  
`user_id` — ID пользователя, сделавшего заказ.
`order_number` — номер заказа пользователя (1-й заказ, 2-й заказ и т.д.).  
`order_dow` — день недели (0 = воскресенье, 1 = понедельник и т.д.).  
`order_hour_of_day` — час заказа (например: 14 = 14:00).  
`days_since_prior_order` — сколько дней прошло с предыдущего заказа (может быть NaN для первого заказа).  

**Связи:**
- `user_id` → `AppUser` (пользователь)
- Связь с продуктами через модель `OrderProduct` (`order_products`)

---

### 2. OrderProduct
Представляет продукты, входящие в заказ.
Содержимое заказов (какие продукты были куплены).

`order_id` — заказ, к которому относится продукт (orders.order_id).  
`product_id` — продукт в заказе (products.product_id).  
`add_to_cart_order` — порядок добавления товара в корзину.  
`reordered` — признак повторной покупки (1 = этот товар уже заказывался пользователем ранее, 0 = заказан впервые).  

**Связи:**
- `order_id` → `Order` (заказ)
- `product_id` → `Product` (продукт)

---

## 🔗 Схема связи

`AppUser` → `Order` → `OrderProduct` → `Product`

- Пользователь может иметь множество заказов
- Заказ содержит множество продуктов
- Каждый продукт может быть в нескольких заказах

---

## 🖥 Админка

В админке доступны:
- Список заказов (`Order`) с фильтрацией по пользователю и дате.
- Содержимое заказа (`OrderProduct`) с возможностью просмотра всех товаров в конкретном заказе.
- Возможность фильтровать и сортировать данные по полям `order_number`, `order_dow`, `reordered` и др.
